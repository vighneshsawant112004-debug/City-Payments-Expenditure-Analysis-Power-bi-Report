# City Payments & Expenditure Analysis Dashboard

##  Project Overview
This project analyzes city-wide financial transactions to uncover spending patterns, vendor distribution, and expense trends.  
An end-to-end data pipeline was built using Python, SQL, and Power BI to transform raw CSV data into actionable business insights.

---

##  Objectives
- Analyze total city expenditure across departments and vendors  
- Identify high-spending areas and key expense categories  
- Track monthly transaction trends  
- Compare contract vs non-contract payments  
- Provide insights for better financial decision-making  

---

##  Tech Stack
- Python (Pandas, NumPy) – Data cleaning & preprocessing  
- SQL (MySQL) – Data storage & querying  
- Power BI – Dashboard & visualization  
- DAX – KPI calculations  

---

##  Data Pipeline
CSV Data → Data Cleaning (Python) → SQL Database → Power BI Dashboard  

---

##  Dashboard Features

### Overview Dashboard
- Total Transaction Amount: **$4.19B**  
- Total Payments: **238K+**  
- Total Vendors: **5500+**  
- Department-wise expenditure analysis  

###  Vendor Analysis
- Top vendor: **Community Behavioral Health (~$924M)**  
- Vendor transaction count analysis  
- Average transaction value insights  

###  Monthly & Department Trends
- Peak spending in **December (~$429M)**  
- Lowest spending in **August (~$199M)**  
- Department-wise monthly patterns  

###  Expense & Contract Analysis
- Highest expense type: **Purchase of Services (~$1.84B)**  
- No-contract payments (~53%) higher than contract-based  
- Vendor distribution by expense type  

---

##  Key Insights
- Majority of spending is on **services**, indicating operational focus  
- A few vendors contribute to a large share of total expenditure  
- Significant number of payments occur **without contracts**  
- Spending shows clear **monthly fluctuations** with peak periods  
- Departments like **Office of BH/MR Services** dominate expenditure
